# Видеообзор платформы

`rastim-review.webm` — 3 минуты 43 секунды, 1280×800.

Это не монтаж и не макеты: запись настоящего приложения с `localhost:5173`.
Браузером управлял скрипт, подписи выводились поверх страницы. Голоса нет —
каждая сцена объясняет себя текстом внизу кадра.

**Чем открыть.** WebM играет Chrome, Edge, Firefox, VLC и Телеграм.
QuickTime и старый проигрыватель Windows — нет.

## Как пересобрать

Запись делает скрипт на Playwright: он открывает Chrome, ходит по ролям
и снимает кадры, которые потом склеиваются в webm. Скрипт лежит во временной
папке сессии — если понадобится другой сценарий или другой текст подписей,
скажите, и я пересниму.

Обязательное условие: приложение должно быть запущено.

```bash
npm --prefix app run dev
```
